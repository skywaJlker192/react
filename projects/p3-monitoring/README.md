# Проект П3 · Мониторинг сайтов группы

Сдача модуля 3 справочника «Angular и React» (М. Н. Макаров). Код проекта в этот репозиторий
не копируется, он лежит в отдельном репозитории `monitoring`.

- Репозиторий: https://github.com/skywaJlker192/monitoring
- Сайт на GitHub Pages: https://skywajlker192.github.io/monitoring/
- Журнал работы с ИИ: [`ai-log.md`](ai-log.md)
- Снимок сообщения бота о сайте, который перестал открываться: `bot-message.png` (добавить перед сдачей)

## Обязательные требования

Отметки `[x]` проверяются по коду и по `npm run build` / `npm run lint`. Пункты про публикацию и
расписание отмечаются после первого запуска на GitHub.

- [x] В `public/data/sites.json` не меньше пяти сайтов, у каждого свой `id` латиницей
- [x] Маршруты `/`, `/site/:id`, `/about` и `*`; в шапке `NavLink`, текущий пункт выделен
- [x] На главной сводка «Не открываются: N из M» / «Все M сайтов открываются» и карточки со ссылкой на страницу сайта
- [x] Страница сайта: название, адрес, число открытий из последних проверок, таблица истории, неудачные проверки выделены
- [x] Неизвестный адрес показывает сообщение и ссылку на главную
- [x] Загрузка `sites.json` и `results.json` в провайдере контекста; страницы и шапка берут данные хуком, без props
- [x] Пока данные грузятся, показана надпись о загрузке; при ошибке выводится сообщение с кодом ответа
- [x] `npm run build` и `npm run lint` проходят без ошибок и предупреждений
- [ ] Сайт опубликован на Pages; прямая ссылка на страницу сайта открывается в новой вкладке и после `F5`
- [ ] Ночная проверка сохраняет результаты коммитом бота и публикует сайт заново
- [ ] Сообщение в Telegram приходит только при изменениях; токен и номер чата лежат в секретах репозитория
