# Доска заявок · frontend

React 19 + TypeScript + Vite. Форма заявки, лента с фильтрами и поиском,
живые обновления из PocketBase, отправка уведомлений в n8n.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
```

Нужен запущенный PocketBase с коллекцией `zayavki`
(схема — `../avtomatizaciya/pocketbase/pb_schema.json`).

## Скрипты

| Команда           | Что делает                          |
| ----------------- | ----------------------------------- |
| `npm run dev`     | дев-сервер Vite с HMR               |
| `npm run build`   | проверка типов + продакшен-сборка   |
| `npm run preview` | посмотреть собранную версию         |
| `npm run lint`    | линтер oxlint                       |

## Переменные окружения

Скопируйте `.env.example` в `.env`, если сервисы не на localhost:

| Переменная        | По умолчанию                                        |
| ----------------- | --------------------------------------------------- |
| `VITE_PB_URL`     | `http://localhost:8090`                             |
| `VITE_NOTIFY_URL` | `http://localhost:5678/webhook/novaya-zayavka`      |

## Структура

```
src/
  types.ts             типы, статусы, категории, чистые функции
  lib/
    pb.ts              клиент PocketBase (общий для realtime)
    api.ts             REST-запросы к коллекции zayavki
    realtime.ts        подписка на события базы
    notify.ts          отправка заявки на вебхук n8n
    format.ts          склонения и «сколько времени назад»
  hooks/
    useTickets.ts      загрузка, ошибка, retry, add/advance/remove
    useFlash.ts        сообщение, исчезающее по таймеру
  components/
    TopBar.tsx         шапка со счётчиками
    TicketForm.tsx     форма новой заявки
    TicketCard.tsx     карточка: статусы, срочность, удаление
    FilterBar.tsx      фильтр-чипы со счётчиками
    Summary.tsx        итоговая строка под лентой
  App.tsx              собирает всё вместе
```

## Поведение

- Фильтр по статусу запоминается в localStorage; `Esc` сбрасывает фильтр и поиск.
- Поиск ищет по названию, комнате, категории и подробностям.
- Удаление двухшаговое: «Убрать с доски» → «Точно убрать?».
- Заявки с пометкой 🔥 «срочно» помечает ИИ-диспетчер в n8n.
- Счётчик новых заявок выводится в заголовке вкладки.
- Если PocketBase недоступен, показывается ошибка с кнопкой повтора;
  если n8n недоступен, заявка всё равно сохраняется, а уведомление пропускается.

## Если что-то не работает

- **«PocketBase не отвечает»** — поднимите базу: `docker compose up -d` в `../avtomatizaciya`.
- **«База отклонила запрос (код 404)»** — не импортирована коллекция `zayavki`.
- **Уведомление не отправлено** — проверьте, что workflow «Диспетчер заявок»
  активирован в n8n (тумблер Active), а не просто открыт в редакторе.
- **CORS-ошибка у вебхука** — приложение должно открываться на `http://localhost:5173`
  (этот адрес разрешён в настройках вебхука).
